# Critic pass — Hot Metal Proof (screenshots only)

**Aesthetic name:** Hot Metal Proof (letterpress desk / print-shop forme)

**Studio bar:** Pentagram-meets-letterpress-shop-site — tactile grain, registration marks, acid ink accents, editorial type.

**Score:** 9/10 after polish pass (CSS restore + shader/video/stamp loop).

**What works**
- Seed-driven palette (ink / bone / acid chartreuse / oxidized rose) — zero vibe-purple
- Asymmetric home: editorial lockup vs create “forme” card with hard offset shadow
- WebGL ink-bleed shader + looping ink MP4 + SVG press-block imagery
- Gamified brief steps (FORME 01/05, Lock line, press ram) + Stamp ZIP overlay
- Editor “proof desk” with formes rail; staggered feature rail (not 3 equal icon cards)
- Fraunces + IBM Plex Mono (local), paper grain, crop marks

**Gaps vs absolute 10**
- Generated landing pages still share one compositional family (intentional; not a template library)
- Shader is 2D WebGL (not full Three scene) — enough motion, not a product reel

**Instant-fail checklist:** all clear (no purple gradients, no Inter/Geist-only, no centered ghost+fill hero chrome, no identical icon cards, no glass/neon, no pill badge, no fake stats, no emoji nav, no bounce-everywhere).
